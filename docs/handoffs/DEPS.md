# DEPS — dependency and root-file requests

Append-only. A role that needs a new crate, npm package, env var name, Makefile target, workspace member or ignore pattern appends one row and does NOT edit the manifest, lockfile, Makefile, .env.example or .gitignore. R4 applies the row, refreshes the lockfile, checks `make verify`, and marks it `done <date>`. Only R4 rewrites lockfiles; everyone else uses `--frozen-lockfile` and `--locked`. If a blocking row is unanswered, proceed behind your own interface (stub or inline helper); never hand-edit a lockfile.
